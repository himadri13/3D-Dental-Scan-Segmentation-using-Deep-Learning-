# 3D-Dental-Scan-Segmentation-using-Deep-Learning-
Surveyed MICCAI 2022 literature and reproduced TGNet/TSegNet on 1,200 scans from 600 patients using an 80/10/10 patient-level split. TGNet achieved 0.9194 mIoU and 0.9537 F1 on 120 test scans. Both models were re-evaluated on an independent dataset, revealing posterior molar segmentation as a key weakness.
